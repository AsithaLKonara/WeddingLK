## 🎯 Project Overview

WeddingLK is a comprehensive wedding planning platform that combines modern web technologies with AI-powered features, mobile application support, and a robust backend infrastructure. The platform serves multiple user roles including regular users, vendors, planners, and administrators.

## 🚀 Major Achievements

### ✅ **Complete Platform Architecture**

- **Backend**: Node.js with Express-style API routes

- **Authentication**: NextAuth.js with role-based access control
