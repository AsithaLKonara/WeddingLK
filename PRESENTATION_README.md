# 🎓 WeddingLK - University Presentation

## 🚀 **QUICK START (5 minutes)**

### 1. **Start Everything**
```bash
# Make scripts executable and start
chmod +x *.sh
./start-presentation.sh
```

### 2. **Access Your App**
- **Frontend**: http://localhost:3000
- **AI Features**: http://localhost:3000/features/ai-enhancements

## 🎯 **What You Built**

**WeddingLK** is a **production-ready, AI-powered wedding planning platform** featuring:

- 🤖 **AI Wedding Style Matcher** - Analyzes preferences, suggests themes
- 💰 **Smart Budget Optimizer** - AI-powered budget allocation
- 👥 **Intelligent Vendor Matching** - ML-based recommendations
- 📸 **AI Photo Generator** - Creates mood boards from descriptions
- 🏢 **Vendor Management System** - Complete vendor lifecycle
- 🏰 **Venue Booking Platform** - Search, availability, pricing
- 💬 **Real-time Chat System** - Built-in messaging
- 💳 **Payment Integration** - Stripe payment processing
- 📱 **Mobile-First Design** - Responsive across all devices

## 🛠️ **Technical Stack**

- **Frontend**: Next.js 15, React 19, TypeScript
- **Backend**: Node.js, Express, MongoDB
- **AI/ML**: OpenAI API, custom algorithms
- **Database**: MongoDB, Redis
- **Deployment**: Docker, Docker Compose
- **Styling**: Tailwind CSS, Framer Motion
- **Authentication**: NextAuth.js, OAuth providers

```bash

```
